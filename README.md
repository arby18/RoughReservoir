# RoughReservoir

RoughReservoir is a high-performance data ingestion platform that enables real-time data processing and efficient management.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/RoughReservoir.git`
2. `cd RoughReservoir`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
